# ChatbotFarm Budget Tracker

This desktop application allows small businesses to track income and expenses locally on Windows.

## Features
- Add income or expense entries with date, category and description.
- View all transactions in a table.
- Delete selected transactions.
- See summary totals for income, expenses and balance.
- Data is saved to `transactions.json` automatically.
- Export transactions to CSV.

## Installation
1. Install **Python 3.8** or newer from [python.org](https://www.python.org/downloads/windows/).
2. Download or clone this repository.

No external Python packages are required.

## Usage
Open a command prompt in the project directory and run:

```bash
python main.py
```

A window titled *ChatbotFarm Budget Tracker* will open. Enter transactions and they will be saved to `transactions.json` in the same directory. Previous data loads automatically on start.
